Objective: Build a Pomodoro-style study app with a coffee-mug theme.
Inspiration: Google's built-in search timer — clean, focused, minimal. The mug replaces the circle as the visual progress indicator, with the countdown centered inside. Cafe ambient background sounds for focus.

Guidelines:
- Timer behavior should be intuitive and predictable.
- Mug visually reflects progress in real-time.
- Prioritize clean, maintainable, and accessible React + TypeScript code.
- Follow consistent styling patterns and reuse Tailwind classes.
- Ensure the app is fully responsive and works well on mobile devices.
- Use ESLint and Prettier; write concise JSDoc for all methods.
- Do NOT run build/dev commands to verify after every change. Only build when explicitly asked or when a full feature is complete.
